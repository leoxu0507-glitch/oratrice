# Oratrice v0.3.0 release notes

v0.3.0 packages the M13-M15 conversation, streaming, and status-companion
work. M16's bounded local acceptance passed on the recorded Windows host.
Use the GitHub release and immutable tag as the publication authority for the
exact source, CI result, source archive manifest, and SHA-256 checksums.

## What's included

- Optional, bounded browser conversation retention with open/delete/clear,
  Markdown and JSON export, visible context-budget feedback, and incomplete
  reply labels. Core, Router, and API remain stateless for conversation history.
- Optional server-sent streaming in the Web UI. Stop ends browser delivery;
  it does not guarantee cancellation of model execution, and the API remains
  busy until that work and cleanup finish.
- A standalone Tk status companion that reads `/status` and opens the Web UI
  on user activation. It does not start or stop Core or model processes.
- A PowerShell 5 native-command capture fix for setup commands that write
  harmless messages to stderr while returning success.

No new vision, cloud-default, voice, model Memory, Tool, or Agent behavior is
part of this release. OpenPets loopback integration remains deferred; the
operator selected the independent status companion.

## Install and verify

Follow the [Windows setup guide](../../README.md#install-and-configure-on-windows).
The tested archive candidate was extracted to a path containing spaces and used Windows
PowerShell 5.1.26100.9711 with Python 3.13.5 and Tk 8.6. Core and Gateway
dependency/import/version checks, local configuration, strict Doctor, and
launcher dry-run passed. In the recorded recovery run, Gateway was installed
into a fresh environment; Core reused the partial environment left by the
initial pip-wrapper failure, so the second Core setup was not a zero-state
install.

Python, Tk, llama.cpp and its compatible runtime DLLs, and model weights are
user supplied. The default profile uses the local GPT-OSS/Gemma path and does
not need cloud credentials or silently fall back to a cloud provider. The
recorded smoke ran with API key variables removed; the launcher created an
ephemeral local Gateway key.

The integrated smoke used the default launcher, reached `/ready`, loaded
`/ui/` and its four JavaScript assets, completed local chat with the expected
`PACKAGE_OK` marker, and completed streaming with `STREAM_OK`. The pet closed
while Core remained ready; closing the launcher console reaped its owned
processes and freed the required ports. See the [M16 acceptance ledger](../validation/M16-RELEASE-SUMMARY.md)
for the measured results and exact limits.

For the published artifact, compare the immutable GitHub `v0.3.0` tag with
`RELEASE-MANIFEST.json`, `SHA256SUMS.txt`, and the exact-source Actions run
linked from the [GitHub release](https://github.com/leoxu0507-glitch/oratrice/releases/tag/v0.3.0).
These release assets define the source and archive identity; this document
does not duplicate those self-referential values.

## Validation summary

The 1800.45-second local session completed 30 sequential HTTP 200 requests
across 15 question/follow-up pairs. Median response time was 11.949 seconds
and maximum was 20.637 seconds. Across 120 resource samples, Core tracked
private memory grew 457.6 MiB overall and 8.4 MiB in the final third; the pet
grew 1.8 MiB. These changes stayed within the predeclared 512 / 256 / 32 MiB
bounds for this run. This result does not establish leak-free continuous
operation or compatibility with other hardware.

## Known limits

- Chat context remains limited to 12 prior messages, a 1536-unit input budget,
  and 256 reply tokens. Browser retention does not increase model context.
- Browser retention is opt-in, unencrypted, and local to the browser profile
  and origin. Users should export conversations they want to preserve.
- Streaming is opt-in and depends on provider support. Stop ends delivery but
  does not guarantee cancellation of inference.
- A manually overridden 64-token request returned HTTP 200 with an empty
  response. The documented 256-token default returned the expected marker in
  later acceptance; the cause of the low-budget result is unknown.
- The native Tk action invoked the system browser opener successfully, but the
  exact newly opened tab was not inspected. The bundled Web page was tested
  separately in Edge 156 through CDP.
- Qwen-VL, cloud inference, voice, cross-session model Memory, Tools, and Agents
  require separate implementation or acceptance.
