## Candidate scope

v0.3.0 packages the M13-M15 development work already integrated into `main`:

- Bounded, optional browser conversation retention, Markdown and JSON export,
  and visible context-budget and incomplete-answer feedback.
- Optional server-sent streaming in the Web UI. Stop ends browser delivery;
  it may not stop model execution, and the API remains busy while that work
  drains.
- A standalone Tk status companion that reads the local `/status` contract and
  opens the Web UI on user activation. It does not start or stop Core or models.

The companion requires a user-supplied Windows Python installation with Tk.
Oratrice's model runtime, compatible DLLs, and model files are also supplied
separately. OpenPets loopback integration, Qwen-VL through LiteLLM, and cloud
inference are deferred. The local default does not require a cloud key and
does not silently fall back to a cloud provider.

## Known limits

- Chat context is limited to 12 prior messages, a 1536-unit input budget, and
  256 reply tokens. Browser retention does not increase model context.
- Browser retention is opt-in, unencrypted, and local to the browser profile
  and origin. Users should export conversations they want to preserve.
- Streaming is opt-in and depends on provider support. Stop ends delivery; it
  does not guarantee cancellation of inference.
- The standalone status pet is not an OpenPets plugin and does not control
  model or Core lifecycle.
- Qwen-VL, cloud inference, voice, cross-session model Memory, Tools, and
  Agents require separate implementation or acceptance.
