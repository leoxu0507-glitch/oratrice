# Oratrice v0.2 candidate

**Status: blocked.** Real restart did not reach readiness and the measured
model-process private memory continued to grow during the 30-minute run. This
is a candidate scope and release checklist, not a release announcement.

## Candidate scope

The generated default profile selects the local GPT-OSS text chain and Gemma
router. Cloud inference is not enabled implicitly; it requires explicit policy
and credentials. Qwen-VL remains optional and deferred.

- **M9 lifecycle:** truthful shutdown state and process ownership, interrupted
  startup rollback, Windows process supervision, and one chat/route admission
  slot per API instance. Offline integration and surrogate-process checks
  passed. Real-model restart and normal user-console acceptance remain pending.
- **M10 portable installation:** generated local configuration, separate Core
  and Gateway environments, strict offline diagnostics, and a portable CI
  definition. The recorded clean Windows/Python 3.13.5 checkout passed setup,
  strict Doctor, dry-run, and 180 offline tests. Remote CI was not dispatched in
  the M10 validation.
- **M11 bounded recent conversation:** the Web UI sends successful recent
  turns in page memory, preserves failed drafts, and resets on refresh or New
  conversation. A history request accepts at most 12 prior messages with a
  1536-unit budget (UTF-8 content bytes plus 32 framing units per message);
  replies default to and are capped at 256 tokens. The body limit is 65536
  bytes. There is no persistent history,
  automatic summary, or streaming. The recorded Python and JavaScript gates
  passed 211 and 11 tests, respectively; Edge acceptance used an injected
  provider.

## Repair follow-up

The follow-up explicitly disables the extra RAM-backed prompt cache for both
required llama.cpp runtimes and adds `--prompt-cache-mib` for a finite per-model
opt-in budget. It also preserves typed startup state and exit codes without
printing exception payloads. The native launcher passed window close and
restart checks with lightweight surrogate processes; the local Python suite
passed 220 tests. These changes have not been revalidated with the real models:
the operator deferred hardware acceptance while other applications were using
the host. The real restart cause and post-fix memory plateau remain unverified.

## Known limits

- The configuration and runtime settings were validated on the recorded
  Windows host. They do not establish compatibility or stable performance on
  all hardware.
- The default profile requires user-supplied Python, llama.cpp and its runtime
  DLLs, and compatible local model weights.
- Qwen-VL through the gateway and real cloud inference are not accepted paths.
  Cloud use requires deliberate configuration and credentials.
- The conversation is page-local and bounded. It does not survive refresh,
  persist to disk, summarize older turns, or stream responses.
- The reply budget can truncate a longer answer. Continue with a short
  follow-up while context remains available, or start a new conversation.
- Close the Oratrice launcher console to stop its owned services. Closing the
  browser tab only ends the browser wait; it does not stop the model stack.
